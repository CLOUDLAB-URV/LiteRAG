# 💻 API Reference

LiteRAG is designed to be easily embedded into larger Python applications, FastAPI servers, or data pipelines.

## Primary Classes

### `LiteRAGConfig`
Validates and stores all system parameters.

```python
from literag import LiteRAGConfig

# Load from YAML (Supports ${ENV_VAR} expansion)
config = LiteRAGConfig.from_yaml("literag_config.yaml")

# Or initialize programmatically
config = LiteRAGConfig(
    data_dir="./data/output",
    api_key="your_api_key",
    max_anchors=5
)
```

### `LiteRAG` (The Engine)
The main orchestrator class.

```python
from literag import LiteRAG

engine = LiteRAG(config)

# 1. Initialize (Loads LanceDB, Parquet files, and warms up the Parallel Explorer)
engine.initialize(force_reload=False)

# 2. Execute Async Query (Recommended)
result = await engine.aquery("What is the impact of edge computing?", expand_query=True)

# 2b. Execute Sync Query
result = engine.query("What is the impact of edge computing?")
```

---

## Output Model: `LiteRAGResult`

All queries return a strongly-typed `LiteRAGResult` dataclass containing the answer, intermediary steps, and rich telemetry.

```python
result = await engine.aquery("How do neural networks work?")

if result.success:
    print(result.answer)
    print(f"Cost: {result.prompt_tokens} tokens")
```

### Key Properties:
*   **`answer`** *(str)*: The final generated response.
*   **`success`** *(bool)*: `True` if the pipeline completed successfully.
*   **`error`** *(str | None)*: Error message if `success` is False.
*   **`context`** *(str)*: The exact prompt assembled by the Reasoning-Chain module.
*   **`anchors`** *(List[Anchor])* : The starting nodes found during Phase 1.
*   **`ranked_entities`** *(List[RankedEntity])* : The final list of merged/ranked entities from Phase 3.

### Telemetry Properties:
*   **`latency_ms`** *(float)*: Total execution time in milliseconds.
*   **`prompt_tokens`** *(int)*: Tokens sent to the LLM.
*   **`completion_tokens`** *(int)*: Tokens generated by the LLM.
*   **`llm_calls`** *(int)*: Number of times the LLM was invoked.
*   **`total_entities_explored`** *(int)*: Total nodes touched by the BFS algorithm.
