# Support

## Questions and Usage Help

For usage questions and troubleshooting:

1. Read the documentation in the docs folder.
2. Open a GitHub issue with context and reproduction details.

## Bug Reports

Use the bug report issue template and include:

- Python version and OS.
- Minimal reproducible example.
- Relevant stack traces.
- Configuration with secrets removed.

## Security Issues

Do not report security issues in public issues.
See SECURITY.md.
